# MuJoCo 通用机器人关节仿真设计方案

## 1. 概述

本文档定义基于 MuJoCo 的通用机器人关节仿真系统设计方案。

目标：

-   支持工业机械臂、人形机器人、移动操作机器人等多类型机器人；
-   实现统一关节控制接口；
-   解耦机器人模型、控制器和仿真执行层；
-   支持 Position、Velocity、Hybrid、Torque 四种控制模式。

------------------------------------------------------------------------

## 2. 设计原则

MuJoCo 负责：

-   动力学计算；
-   接触求解；
-   actuator 执行；
-   传感器模拟。

控制框架负责：

-   控制模式管理；
-   控制参数转换；
-   安全限制；
-   状态反馈。

核心原则：

> 机器人模型描述机械属性，控制器描述运动行为。

------------------------------------------------------------------------

## 3. 控制模式

  模式       参数
  ---------- ---------------------------
  Position   stiffness + damping_ratio
  Velocity   gain
  Hybrid     kp/kd/tau_ff
  Torque     tau

------------------------------------------------------------------------

# 4. Position 模式

## 4.1 设计目标

提供类似工业机器人和 Franka 阻抗控制的接口。

用户指定：

-   目标位置；
-   期望刚度；
-   阻尼特性。

参数：

    position
    stiffness
    damping_ratio

刚度表示：

> 关节偏离目标位置时产生恢复力矩的能力。

控制关系：

τ = K(qd-q)

阻尼比用于描述系统振荡特性：

D = 2ζ√(JK)

其中：

-   J 为关节惯量；
-   K 为刚度；
-   ζ 为阻尼比。

------------------------------------------------------------------------

# 5. Velocity 模式

## 5.1 设计目标

提供速度闭环控制。

参数：

    velocity
    gain

控制关系：

τ = Kv(q̇d-q̇)

适用于：

-   移动底盘；
-   速度控制任务；
-   伺服系统。

------------------------------------------------------------------------

# 6. Hybrid 模式

## 6.1 设计目标

提供类似 Unitree LowCmd 的低层控制接口。

参数：

    position
    velocity
    kp
    kd
    tau_ff

控制关系：

τ = τff + Kp(qd-q) + Kd(q̇d-q̇)

适用于：

-   人形机器人；
-   全身控制；
-   MPC；
-   强化学习。

------------------------------------------------------------------------

# 7. Torque 模式

提供最低层动力学控制接口。

参数：

    tau

控制关系：

τ = τd

适用于：

-   动力学控制；
-   力矩控制算法。

------------------------------------------------------------------------

# 8. 控制参数设计

不推荐：

    joint:
      kp:
      kd:

原因：

-   参数数量多；
-   不同机器人难复用；
-   调试成本高。

推荐：

Position：

    stiffness
    damping_ratio

Velocity：

    gain

Hybrid：

    kp
    kd
    tau_ff

Torque：

    tau

------------------------------------------------------------------------

# 9. 仿真执行流程

    Joint Command
          |
    Joint Controller
          |
    Torque Command
          |
    Safety Layer
          |
    MuJoCo Actuator
          |
    Physics Simulation
          |

# 10. 安全层

所有控制模式统一经过：

-   位置限制；
-   速度限制；
-   力矩限制；
-   力矩变化率限制。

# 13. 总结

MuJoCo 通用机器人关节仿真框架采用：

    Robot Model
    +
    Joint Controller
    +
    Safety Layer
    +
    MuJoCo Actuator

控制模式：

-   Position：stiffness + damping_ratio
-   Velocity：gain
-   Hybrid：kp/kd/tau_ff
-   Torque：tau

该方案兼顾通用性、可维护性以及真实机器人接口迁移能力。
